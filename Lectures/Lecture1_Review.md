### 0. A New Way to Learn Programming


A program can be syntactically correct and still be wrong.


For example:


```java
public static boolean isAdult(int age) {
    return age > 18;
}

This code compiles.

But if the requirement is:

A person is an adult when age is 18 or older.

then the code is logically wrong.

The correct version is:

public static boolean isAdult(int age) {
    return age >= 18;
}

Therefore, programming requires more than syntax.

We use the following cycle:

Understand the requirement
        ↓
Design the solution
        ↓
Write code
        ↓
Predict the result
        ↓
Run / Test
        ↓
Debug
        ↓
Explain
        ↓
Modify / Improve
```

2.6 Method Overloading

Method overloading means:

Multiple methods in the same class have the same name but different parameter lists.

Example:

public static int max(int a, int b) {
    return a > b ? a : b;
}


public static double max(double a, double b) {
    return a > b ? a : b;
}


public static int max(int a, int b, int c) {
    return max(max(a, b), c);
}

These are overloaded because the parameter lists differ.

max(int, int)
max(double, double)
max(int, int, int)
Important: Return Type Alone Is NOT Overloading

This is NOT allowed:

public static int test(int x) {
    return x;
}


public static double test(int x) {
    return x;
}

The parameter list is identical.

Changing only the return type does not create an overload.

4.8 Comparing Strings

Do NOT use:

to compare String contents.

Use:

equals() compares contents when implemented appropriately by the class.

Safer Pattern

Instead of:

when name might be null, we can write:

"Hanif".equals(name)

because the literal "Hanif" is not null.

7.1 Worked Example: Password Validation

Suppose a password is valid if it contains:

uppercase letter
lowercase letter
digit

We can use Boolean flags.

public static boolean isPasswordValid(String password) {


    boolean upper = false;
    boolean lower = false;
    boolean digit = false;


    for (int i = 0; i < password.length(); i++) {


        char c = password.charAt(i);


        if (Character.isUpperCase(c))
            upper = true;


        else if (Character.isLowerCase(c))
            lower = true;


        else if (Character.isDigit(c))
            digit = true;
    }


    return upper && lower && digit;
}
Trace the Method

digit = false

No change.

Final:

Therefore:

becomes:

8.2 Selection

Selection allows the program to choose which code to execute.

if
if(age >= 18)
    System.out.println("Adult");
if / else
if(age >= 18)
    System.out.println("Adult");
else
    System.out.println("Minor");
Multiple conditions
if(score >= 90)
    grade = 'A';
else if(score >= 80)
    grade = 'B';
else if(score >= 70)
    grade = 'C';
else
    grade = 'F';

The conditions are checked from top to bottom.

Once one condition is true, the remaining branches are skipped.

8.3 Common if Error

Consider:

if(score >= 50)
    System.out.println("Pass");


System.out.println("Congratulations!");

Only the first statement belongs to the if.

If two statements should be controlled:

if(score >= 50) {
    System.out.println("Pass");
    System.out.println("Congratulations!");
}

Use braces when they improve clarity.

8.4 Conditional Operator

Simple:

if(num1 >= num2)
    return num1;
else
    return num2;

can be written:

return (num1 >= num2) ? num1 : num2;

Structure:

condition ? valueIfTrue : valueIfFalse

Do not use the conditional operator when the logic becomes difficult to read.

8.5 switch

Use switch when comparing one expression against several discrete values.

Example:

switch(operation) {


    case 1:
        withdraw();
        break;


    case 2:
        deposit();
        break;


    case 3:
        displayBalance();
        break;


    default:
        System.out.println("Invalid option");
}
Why break?

Without break, execution can continue into the next case.

Example:

switch(x) {


    case 1:
        System.out.println("One");


    case 2:
        System.out.println("Two");
}

If:

x = 1

the output can be:

One
Two

This is called fall-through.

9.7 Choosing the Correct Loop

17. Shallow Copy vs Deep Copy

Consider:

Student s1 = new Student();
Student s2 = s1;

This does NOT create a new Student object.

It creates another reference to the same object.

s1 ─────┐
        ↓
     Student
        ↑
s2 ─────┘

This is commonly described as a shallow/reference copy.

Deep Copy

A deep copy creates a separate object.

For example:

Student s2 = new Student(s1);

assuming the constructor creates a new Student object.

Then:

s1 ──→ Student A


s2 ──→ Student B

Changing Student A does not automatically change Student B.

18. static vs non-static

This distinction is extremely important.

18.1 Non-static

Belongs to an object.

Example:

private int hr;

Each Clock can have a different value.

Clock c1 = new Clock();
Clock c2 = new Clock();

Conceptually:

c1.hr = 8
c2.hr = 15
18.2 static

Belongs to the class.

Example:

private static String brand;

There is one class-level value shared by Clock objects.

Use:

Clock.printBrand();

rather than creating an object merely to access the static method.

18.3 Static Method Rule

A static method can directly access static members.

Example:

public static void printBrand() {
    System.out.println(brand);
}

But it cannot directly access a particular object's:

hr
mi
se

because a static method does not automatically know which Clock object you mean.

18.4 Non-static Method

A non-static method belongs to an object.

public void increaseHr() {
    hr++;


    if(hr == 24)
        hr = 0;


    System.out.println(brand);
}

It can access:

instance/non-static members
static members

because the method is being executed in the context of a particular object.

public class Student {

Output:

12

The method calculates:

sum of even numbers from 1 through n
22. Common Mistakes to Watch For
Mistake 1: Using == for Strings

Bad:

if(name == "Alice")

Better:

if(name.equals("Alice"))
Mistake 2: Off-by-one errors

Bad:

for(int i = 0; i <= text.length(); i++)

Correct:

for(int i = 0; i < text.length(); i++)
Mistake 3: Forgetting that indexes start at 0

For:

Java

indexes are:

J a v a
0 1 2 3
Mistake 4: Infinite loops

Bad:

int i = 0;


while(i < 10) {
    System.out.println(i);
}

There is no update to i.

Mistake 5: Confusing length and length()

Array:

array.length

String:

str.length()
Mistake 6: Forgetting return

This method is incomplete:

public static int square(int x) {
    x * x;
}

Correct:

public static int square(int x) {
    return x * x;
}
23. AI-Assisted Programming

AI tools can produce Java code very quickly.

For example, you might ask:

Write a Java method that determines whether a String contains a digit.

An AI might produce:

public static boolean containsDigit(String text) {


    for(int i = 0; i < text.length(); i++) {


        if(Character.isDigit(text.charAt(i)))
            return true;
    }


    return false;
}

This looks correct.

But a programmer should still ask:

Why does it work?
What happens if text is empty?
What happens if text is null?
Why does the loop use < rather than <=?
Why does the method return true immediately?
What happens after return?
23.1 AI Does Not Remove the Need to Understand Code

Suppose an AI gives you:

for(int i = 0; i <= text.length(); i++)

It may look reasonable.

But it is wrong.

For:

"Java"

the valid indexes are:

0 1 2 3

There is no index 4.

Therefore:

text.charAt(4)

causes an exception.
