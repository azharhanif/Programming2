# Programming 2 — Recursion Lab Bundle 

This bundle contains a recursion lab redesigned to make the **base case** and **general pattern** explicit in every recursive solution.

## Design decisions
- familiar OOP examples: Animal, Vehicle, Bank
- recursion written without loops in the recursive solutions
- helper methods with `index` used to make the recursion pattern visible
- starter version included

## Folder structure
- `docs/recursion-lab-student.md`

- `starter/src/Main.java`


## Emphasis
For this lab:
- **Base case** = simplest case with known direct answer
- **General pattern** = solve one current element, then recurse toward the base case
