
# Exception Handling Lab Bundle

This bundle contains a Programming 2 lab based on:
- Lecture 12: Exception Handling
- Lecture 7: Polymorphism

## Structure
- `docs/` — student handout and teacher solution in Markdown
- `starter/` — starter Maven project with TODOs
- `solution/` — complete Maven project with solutions and JUnit tests

## Topics covered
- default exception handler
- `try-catch`
- specific vs general catches
- meaningful handlers with `e.getMessage()`
- `throws`
- user-defined checked exceptions
- common OOP examples: animals, vehicles, bank accounts
