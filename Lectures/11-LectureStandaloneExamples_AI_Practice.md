## Code microscope protocol

For each file:

### 1. Predict

Write the expected behavior.

### 2. Annotate

Mark:

```text
input
state
method call
return
exception
object creation
```

### 3. Run

Confirm or reject the prediction.

### 4. Break

Change exactly one line.

Predict what changes.

### 5. AI-assisted extension

Ask AI for a small extension.

Examples:

- add a second implementation of `Printable`;
- add another recursion test;
- add another exception type;
- add another serialization field;
- add a second comparator.

### 6. Human modification

Change the AI-generated implementation.

### 7. Explain

Students explain the final code without AI.

## Instructor use

These examples are particularly useful for five-minute classroom checks:

> "Don't run it yet. Tell me what Java will do."

This directly tests conceptual understanding rather than typing ability.
