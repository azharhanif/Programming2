# Review Lecture Examples — AI-Aware Redesign

**Repository area:** `Lectures/CodeExamplesInLectures/ReviewLectureExamples`

## Purpose

The review examples should become a bridge between isolated syntax exercises and integrated Programming 2 reasoning.

## Activity A — predict

For each review example:

1. identify the classes;
2. identify object creation;
3. identify references;
4. identify method calls;
5. predict output;
6. run and compare.

## Activity B — explain a bug

Students choose one line and intentionally change it.

Examples:

```text
remove an override
change a reference type
change an index boundary
change a comparison
remove a base case
change a catch type
```

Predict the result before compiling.

## Activity C — AI-assisted integration

Ask AI:

> Combine two concepts from the review examples into one small Java program.

Students must select the two concepts and explain why the combination is meaningful.

## Activity D — human redesign

Students must then add a third concept themselves.

For example:

```text
Inheritance + ArrayList + Comparator
```

or:

```text
Polymorphism + Exception Handling + TextIO
```

## Final check

Students must write:

```text
Concept 1:
Concept 2:
Concept 3:
Where each appears in the code:
Why each is needed:
One edge case:
```
